# ИТ в сфере безопасности — 1-МГ-63

Одностраничный сайт с учебными материалами по дисциплине **«Информационные технологии в сфере безопасности»** для группы 1-МГ-63.

**Что есть:** разделы «Лекции» (вёрстка, JavaScript, нейросети и ИИ, дополнительный материал, видеолекции), «Практики» (портфолио, дашборд, ресурс по техносферной безопасности), «Экзамен» (курсовая, билеты). Контент подгружается из `index.json`, материалы — HTML/CSS/JS без фреймворков, mobile-first.

**Локально:** откройте `index.html` или `npx serve .`. Для публикации — GitHub Pages.
