## Описание задания

Создайте одностраничный веб-сайт — тематический информационный или образовательный ресурс по техносферной безопасности и инженерной защите окружающей среды (правила, рекомендации, памятки, справочные материалы, оповещение или визуализация данных о безопасности).

## Требования к тематике

Содержимое должно относиться к одной из тем (или их комбинации), например:

- Безопасность жизнедеятельности и защита окружающей среды — правила, рекомендации, памятки
- Техносферная безопасность — основные понятия, направления
- Инженерная защита окружающей среды — справочный или образовательный материал (нормативы, классификации, меры защиты)
- Оповещение и информирование — действия в чрезвычайных ситуациях, контакты экстренных служб, чек-листы
- Визуализация данных о безопасности — интерактивная схема, таблица, «карта» рисков или мер (условные данные допустимы)

Тему можно сузить или расширить по согласованию с преподавателем.

## Технические требования

### Выбор технологий

Стандартный стек: HTML, CSS, JavaScript (без фреймворков).

### Обязательное требование: использование нейросетей

Задание обязательно должно быть выполнено с использованием нейросетей. Допустимые инструменты:

- DeepSeek
- ChatGPT
- Cursor
- GigaChat
- Другие аналогичные инструменты

**Важно:** на сайте необходимо указать:

- Какую нейросеть вы использовали
- Сколько времени заняло выполнение задания

Эту информацию разместите в подвале (footer) сайта, например: *GigaChat — 20 минут*.

### Требование к JavaScript функционалу

На странице обязательно должен быть реализован функционал на JavaScript.

**Требование:** в подвале сайта укажите, какой функционал на JavaScript реализован (например: «Раскрывающиеся блоки (аккордеон)», «Чек-лист с отметками», «Переключение темы» и т.д.)

Примеры подходящего функционала:

- Раскрывающиеся блоки (аккордеон) для разделов
- Чек-лист с отметками «сделано»
- Переключение темы (светлая/тёмная) или фильтр по категориям
- Простая визуализация (таблица, схема, список с подсветкой по выбору)

### Требования к верстке

- Аккуратная и единообразная верстка
- Системный подход к дизайну
- Современный внешний вид
- Количество контента определяете самостоятельно

### Подход к разработке: Mobile First

**Обязательное требование:** верстка должна быть выполнена по принципу Mobile First.

Если вы не знакомы с этим подходом, изучите его самостоятельно.

## Структура контента

Содержимое страницы должно включать:

- Заголовок и краткое введение
- Несколько смысловых блоков (разделы по выбранной теме)
- При необходимости — ссылки на нормативные документы или источники
- В подвале (footer) указать: использованную нейросеть и время выполнения, реализованный функционал на JavaScript

## Требования к оформлению

- Современный, читаемый дизайн
- Адаптивная верстка (Mobile First)
- Единообразие элементов
- Удобная навигация по разделам (якорные ссылки или плавная прокрутка)

## Результат

### Формат сдачи

- Проект должен быть собран в архив
- Архив должен содержать все файлы проекта (HTML, CSS, JS, изображения и т.д.)

Либо ссылка на репозиторий (GitHub и т.п.) с описанной структурой.

## Полезные советы

- Опирайтесь на актуальные информационные ресурсы по техносферной безопасности и экологической тематике (официальные сайты органов власти, профессиональные порталы, открытые нормативные и справочные базы, научные и аналитические публикации); при использовании обязательно указывайте источники
- Сделайте контент полезным: короткие пункты, понятные формулировки
- Убедитесь, что сайт корректно отображается на мобильных устройствах
- Протестируйте интерактивные элементы на JavaScript
- Убедитесь, что в подвале указана требуемая информация

## Критерии оценки

- Качество верстки (аккуратность, единообразие)
- Соответствие принципу Mobile First
- Наличие и качество JavaScript функционала
- Соответствие тематике (техносферная безопасность, инженерная защита окружающей среды)
- Современность дизайна
- Полнота и качество контента
- Указание использованной нейросети и времени выполнения
- Общее впечатление от сайта
