## Курсовая работа по дисциплине «Информационные технологии в сфере безопасности»

### Цель курсового проекта

Разработать и описать **функциональный веб-проект**, направленный на решение одной из актуальных проблем в сфере техносферной безопасности и инженерной защиты окружающей среды.

### Что нужно сделать студенту

1. **Выбрать тему** из предложенного списка (или согласовать свою с преподавателем).
2. **Реализовать рабочий прототип веб-приложения**, используя современные технологии фронтенда (HTML, CSS, JavaScript).
3. **Разместить проект** на GitHub Pages или аналогичной хостинг-платформе.
4. **Оформить пояснительную записку** в соответствии со структурой ниже.

---

### Структура пояснительной записки

1. **Титульный лист**  
   Оформляется по выданному шаблону (будет предоставлен преподавателем).

2. **Введение**  
   - Актуальность темы.  
   - Цель проекта.  
   - Задачи, которые необходимо решить.

3. **ГЛАВА 1. Анализ предметной области и проектирование системы**
   - **1.1. Актуальность и проблематика**  
     Обоснование важности выбранной темы для сферы техносферной безопасности. Анализ существующих проблем.
   - **1.2. Анализ аналогов**  
     Обзор и сравнительный анализ существующих решений (российских и/или зарубежных) с указанием их достоинств и недостатков.
   - **1.3. Цели и задачи проекта**  
     Чёткая формулировка цели создания веб-приложения и перечень конкретных задач.
   - **1.4. Функциональные и нефункциональные требования**  
     Описание того, что должна делать система (функции) и каким требованиям должна соответствовать (производительность, надёжность, удобство использования и т.д.).
   - **1.5. Проектирование структуры и интерфейса**  
     Логическая структура приложения, описание основных страниц/экранов и пользовательских сценариев.

4. **ГЛАВА 2. Выбор и обоснование технологий разработки**
   - **2.1. Клиентские технологии**  
     Описание и обоснование выбора стека для фронтенда: HTML5, CSS3, JavaScript (ES6+), использование семантической вёрстки, адаптивного дизайна, CSS Grid/Flexbox и т.п.
   - **2.2. Инструменты и платформы для разработки**  
     Git, GitHub, платформа развёртывания (GitHub Pages и др.).
   - **2.3. Использование искусственного интеллекта в разработке**  
     - Краткое описание генеративных AI‑моделей.  
     - Примеры используемых сервисов (DeepSeek, ChatGPT, Claude и др.).  
     - Подробно описать, **как именно ИИ использовался в проекте**:  
       генерация шаблонного кода, помощь в написании функций на JavaScript, исправление ошибок, создание контента, идеи для дизайна и др.  
     - Указать, **какие промпты** (запросы) оказались наиболее эффективными.

5. **ГЛАВА 3. Реализация веб-приложения**
   - **3.1. Описание процесса разработки**  
     Поэтапное описание создания приложения: какие модули/компоненты разрабатывались и в какой последовательности.
   - **3.2. Реализация ключевых функций**  
     Детальное описание реализации основных задач из Главы 1 (работа с внешним API, интерактивная карта, алгоритмы расчёта, база данных — если есть, и т.д.).
   - **3.3. Интерфейс и пользовательский опыт (UX)**  
     Описание итогового интерфейса, удобства использования, адаптивности, скриншоты ключевых страниц.
   - **3.4. Ссылка на работающий проект**  
     Активная ссылка на проект (GitHub Pages или аналог).
   - **3.5. Ссылка на репозиторий с исходным кодом**  
     Ссылка на GitHub‑репозиторий с кодом.

6. **Заключение**  
   Выводы по работе, подведение итогов, оценка достижения цели, возможные направления дальнейшего развития проекта.

7. **Список использованных источников**

8. **Приложения** (при необходимости)

### Темы курсовых проектов

1. **Веб‑платформа мониторинга качества воздуха в городской среде**  
   Сбор данных с открытых API, визуализация загрязнений, рекомендации по экобезопасности.

2. **Интерактивная карта экологических рисков региона**  
   Интеграция картографических сервисов, отображение предприятий, зон загрязнения, свалок.

3. **Сайт для информирования населения о действиях при чрезвычайных ситуациях**  
   Адаптивный дизайн, пошаговые инструкции, интерактивные сценарии поведения.

4. **Электронная база данных по утилизации отходов и переработке материалов**  
   Поиск по видам отходов, предприятиям, контактам, нормативам.

5. **Веб‑приложение для расчёта экологического следа предприятия или гражданина**  
   Автоматизация расчётов по выбросам, воде, отходам.

6. **Образовательный портал по техносферной безопасности**  
   Мультимедийные материалы, тестирование, элементы геймификации обучения.

7. **Система онлайн‑оповещения о неблагоприятных погодных и техногенных условиях**  
   API погоды, SMS/email‑уведомления, прогнозирование рисков.

8. **Информационный ресурс по экологическому законодательству РФ и ЕС**  
   Структурированный поиск по документам, обновляемая база данных.

9. **Веб‑симулятор для обучения действиям в случае утечки опасных веществ**  
   Интерактивные сценарии, визуализация зон поражения, тестирование.

10. **Сайт‑навигатор экологических инициатив и волонтёрских проектов региона**  
    Карта мероприятий, регистрация участников, отчётность по акциям.
